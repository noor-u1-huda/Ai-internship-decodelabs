# DecodeLabs Project 3
## Content-Based Recommendation System Using AI

This project implements a Content-Based Recommendation System using TF-IDF Vectorization and Cosine Similarity in Python.

## Features
- Movie Dataset Creation
- Text Vectorization using TF-IDF
- Cosine Similarity Calculation
- Movie Recommendation System
- Top-N Recommendations
- Similarity Score Ranking
- Recommendation Explanation
- Data Visualization

## Technologies Used
- Python
- Scikit-learn
- Pandas
- Matplotlib
