# DecodeLabs Project 4
## AI-Based Text Recognition System using OCR

This project implements an AI-Based Text Recognition System using Optical Character Recognition (OCR) in Python.

The system reads text from images by applying image preprocessing techniques and OCR technology.

## Features
- Image Loading
- Grayscale Conversion
- Noise Removal
- Image Thresholding
- Text Extraction using OCR
- Processed Image Display
- Text File Saving
- AI-Based Text Detection

## Technologies Used
- Python
- OpenCV
- Pytesseract
- Matplotlib
- NumPy

## How the System Works
1. Load input image
2. Convert image to grayscale
3. Remove image noise
4. Apply thresholding
5. Extract text using OCR
6. Display recognized text
7. Save extracted text into file

## Output
The system:
- detects text from images
- displays recognized text
- saves extracted text in a text file
